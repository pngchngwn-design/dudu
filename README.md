# 快乐点读乐园 · 三年级英语点读打卡网站

给三年级小朋友的英语点读学习乐园：标准读音、跟读打分、每日打卡、多套卡通主题背景，纯网页零依赖。

## 功能一览

| 模块 | 说明 |
|------|------|
| 🏠 点读台 | 26 个字母自然拼读表（序号/字母/音标/拼读/谐音），点读 + 单个跟读 + 连续跟读 + 慢速朗读 |
| 📚 单词库 | 三年级 8 大主题单词（动物/颜色/数字/水果/文具/身体/家人/天气），点读 + 连续跟读 |
| ✏️ 句子 | 三年级常用句子 + 自由输入任意课文句子点读、逐句跟读打分 |
| 📁 资源 | 上传图片（自动压缩优化）/ 视频 / 任意网站链接，挂接点读文本后可点读跟读 |
| 🏆 打卡 | 按学生姓名独立记录；连续打卡/累计天数/平均分统计；打卡日历；明细表；一键打印成绩单；导出/导入备份 |
| 🎨 主题 | 6 套卡通背景：汪汪救援队 / 国风小哪吒 / 飞机小英雄 / 超人小猪侠 / 梦幻大城堡 / 星空糖果屋 |

## 快速开始

### 本地使用（无需任何安装）
直接双击 `index.html` 即可在浏览器中打开使用。

> 注意：跟读打分功能基于浏览器语音识别，推荐使用 **电脑版 Microsoft Edge 或 Chrome** 打开（需允许麦克风）；点读朗读、打卡、资源等其他功能所有浏览器均可用。

### 本地服务器（推荐，体验更完整）
```bash
# 在项目目录下任选一种方式
python -m http.server 8080
# 或
npx serve .
```
然后浏览器访问 http://localhost:8080

### 随时随地使用（部署到免费静态托管）
本站为纯静态网站，把整个文件夹上传到任意静态托管即可获得一个公网链接：
- **GitHub Pages**（免费）：新建仓库 → 上传全部文件 → Settings → Pages → 选择 main 分支 → 得到 https://用户名.github.io/仓库名
- 其他可选：Gitee Pages、Netlify、Vercel、腾讯云 COS 静态网站 等

部署完成后，把链接发到手机/平板/电脑浏览器打开即可，只要能上网都能用。

## 数据保存说明

- 学习进度、打卡记录、学生名单保存在**当前浏览器的本地存储**中，换设备/换浏览器不会自动同步。
- 换设备前，请到「打卡」页 → **导出备份**，在新设备上 **导入备份** 即可迁移全部数据。
- 上传的图片视频保存在浏览器 IndexedDB 中，同一浏览器中长期有效。

## 技术栈

- 纯原生 HTML + CSS + JavaScript（无任何外部依赖、无 CDN、无构建工具）
- Web Speech API（speechSynthesis 朗读 / SpeechRecognition 跟读识别）
- localStorage（进度与打卡记录） + IndexedDB（上传的图片视频）
